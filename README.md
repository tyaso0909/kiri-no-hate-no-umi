# 霧の果ての海

百年に一度、霧が晴れる。四人の船長が同じ海へ漕ぎ出し、宝箱を積んでは港へ戻る。積むほど稼げて、積むほど狙われる。

共通の山札を引き合い、宝箱を集めて港で換金する、2〜4人用の対戦カードゲームです。ブラウザだけで遊べます。

## 遊び方

- **オンライン対戦**：船長の名前と合言葉を入れて「ルームに入る／作る」。同じ合言葉を入れた人が同じルームに集まります。最初に入った人がホストになり、空いている席には出航時にCPUが入ります。
- **ひとりプレイ**：CPU 3隻と対戦します。通信は使いません。
- 勝利に必要な金貨は 20／30／40 枚から選べます。
- スマホは常に横画面で表示されます（縦に持っている場合は画面ごと回転します）。「全画面」ボタンも使えます。
- 画面上部の航路で、各船が港から「霧の果て」へどこまで進んだか（金貨の枚数）が分かります。
- カードを引くと、山札から飛び出して表に返る演出があります（アクションカードの表は引いた本人だけに見えます）。各行動・ハプニングにはイラストが付いています。
- ゲーム中はBGM・効果音・波の音が流れます。画面右上の「音の設定」で、それぞれのオン・オフと音量を変えられます（設定はブラウザに保存）。

## ルール

1. 自分の番に、共通の山札から1枚引く。
2. **アクションカード**には行動が上から5つ並んでいる。使えるのは上から「船員の数＋1」個までで、その中から1つを選んで行う。
3. **ハプニングカード**はすぐに効果を解決する。「悪いこと」は風の護符1枚で防げる（自動で使われる）。
4. 宝箱の中身は持ち主にしか見えない。**港で換金**して初めて金貨になる。船に積める宝箱は5個まで。
5. 目標の金貨を集めた船長が、その場で勝利。

### 船員

- 全員、最初は船員1人で出航する（最大4人）。
- 船員が多いほど、アクションカードで選べる行動が増える（船員1人なら2つ、4人なら5つ全部）。
- **船員募集**：金貨3枚を払えば必ず1人増える。払わなければ50%の確率で増える。

### 山札（100枚）

アクションカード66枚（行動の並び22パターン）と、ハプニングカード34枚。

### アクション

| 行動 | 効果 |
| --- | --- |
| 航海 | 宝箱を1個得る |
| 深海探索 | 宝箱を2個見て、1個だけ取る |
| 港で換金 | 宝箱をすべて開けて金貨にする |
| 略奪 | 誰か1人の宝箱を、見ずに1個奪う |
| 海図を読む | 山札の上2枚を見て、並べ替える |
| 修理 | 風の護符を1枚得る（最大2） |
| 錨を下ろす | 次の自分の番まで、略奪・幽霊船・大嵐・海の怪物から宝箱を守る |
| 嵐の海域へ | サイコロを振るたびに宝箱を1個引き上げる（1個目からサイコロが必要）。1が出たらここで引き上げた宝箱をすべて失う（最大3個）。1個以上引き上げたら、いつでもやめて持ち帰れる |
| 闇の買い取り | 自分の宝箱（王の宝箱以外）を伏せて混ぜ、1つ選んで中身に関係なく金貨2枚で売る |
| 船員の出稼ぎ | 船員を1人出稼ぎに出す（今は1人減る）。自分の番が3回来たときに、金貨2枚を持って戻る |
| 船員募集 | 船員を1人増やす（金貨3で確実、無料なら50%） |

### ハプニング（34枚）

| 名前 | 分類 | 効果 |
| --- | --- | --- |
| 沈没船の発見 ×3 | 良いこと | 宝箱を2個得る |
| イルカの群れ ×3 | 良いこと | 金貨が最も少ない人が宝箱を2個得る |
| 人魚の歌 ×3 | 良いこと | 全員、風の護符を1枚得る |
| 大嵐 ×2 | 悪いこと | 全員、宝箱を1個海に捨てる（護符で防げる） |
| 大渦 ×2 | 悪いこと | 自分の宝箱を半分（切り捨て）失う（護符で防げる） |
| 海の怪物 ×2 | 悪いこと | 宝箱を一番多く積んでいる人が2個失う（護符で防げる） |
| 無風 ×2 | 悪いこと | 次の自分の番は休み（護符で防げる） |
| 幽霊船 ×2 | 駆け引き | 好きな相手1人の宝箱を1個、海に捨てさせる |
| 密輸船 | 駆け引き | 金貨が最も少ない人が、宝箱を一番多く持つ人と宝箱をすべて交換する |
| 賭けの酒場 ×2 | 駆け引き | サイコロを振る。偶数で金貨+3、奇数で金貨−2。見送り可 |
| 伝説の島 | 駆け引き | 王の宝箱（金貨10）を得る。表向きで、換金するまで奪われうる |
| 新しい仲間 ×3 | 良いこと | 港で出会った船乗りが仲間になる。船員+1（最大4人） |
| 船員の離脱 ×2 | 悪いこと | 船員が1人、船を降りる（護符で防げる） |
| 船員の引き抜き ×2 | 駆け引き | 好きな相手1人から船員を1人引き抜く（自分+1、相手−1） |
| 海賊の通行料 ×2 | 駆け引き | 金貨2枚を払う／宝箱を1個差し出す／戦う（サイコロ：偶数で宝箱+1、奇数で宝箱−2）から選ぶ |
| 漂流者 ×2 | 駆け引き | 助ける（船員+1、食料として宝箱を1個失う。宝箱がないと助けられない）か、見捨てるかを選ぶ |

## オンライン対戦のしくみ

GitHub Pages 版は、[PeerJS](https://peerjs.com/) を使ってホストのブラウザに参加者が直接つながります。サーバーの用意やアカウント登録はいりません。

- ゲームの進行とCPUの操作はホストのブラウザが行います。ホストがページを閉じるとルームは終わります。
- 参加者の通信が切れると、その船はCPUが引き継ぎます。
- 会社や学校のネットワークなど、直接接続が通らない環境ではつながらないことがあります。
